# wllmvg.github.io

This repository is the source code of my personal portfolio: **[wllmvg.github.io](https://wllmvg.github.io)**.

I'm William Vega, a Junior Developer. At work I build native iOS (Swift, SwiftUI) and Android (Java) apps; on my own I build full-stack web products. This site is where recruiters and technical leads can see that work in one place: who I am, what I've shipped, and how to reach me.

## What the site shows

- **Current role**: what I do as a Junior Developer at KL Security (kept generic, the work is under an NDA).
- **Thesis**: an academic management platform running in production on AWS EC2, used by ~64 students, graded 4.9 / 5.0.
- **Projects**: nexo-app, usage-for-claude, Scheduly, Rifally, TokenShift, a student finance mobile app and Gridwall, each with a live link or its code. They can be filtered by Web, Mobile or Desktop.
- **Stack, path and certificates**: tools I use, my experience and education, and certificates you can open as PDFs.
- **CV**: downloadable in English or Spanish, depending on the language you're reading in.

The whole site works in English and Spanish, on phones and on desktop.

## How it's built

- **React 19 + TypeScript + Vite**: a single page, with all the text in one file (`src/content.ts`) in both languages.
- **Design**: inspired by Swiss poster design. A visible 12-column grid, one typeface (Archivo), a scale of grays and one blue reserved for "now": my current role and the active filter.
- **Motion**: framer-motion for the project filter and CSS for the rest. It respects the "reduce motion" setting of your device.
- **Hosting**: GitHub Pages.
